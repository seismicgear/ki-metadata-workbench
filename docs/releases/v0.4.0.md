# METADATA 0.4.0

A free standalone metadata utility by Kuykendall Industries, prepared for the Array launcher.

## Downloads

- **Windows x64 Portable.exe:** open without an installer.
- **Windows x64 Setup.exe:** per-user installation and shortcuts.
- **Source.zip:** complete source, build scripts, tests, documentation, bundled engines and third-party licenses/sources.
- **SHA256SUMS.txt** and **BUILD_PROVENANCE.json:** download integrity and the source/build identity.

The app includes its native engine, ExifTool, FFmpeg and ffprobe. No account, activation, Node, Rust or separate media tools are required for employee use.

## Combined upgrade

- Retains the 0.2.0 strict JPEG/PNG/APNG/WebP privacy engine and its unchanged regression suite.
- Retains the 0.3.0 extended image/RAW, audio/video, PDF, Office and OpenDocument workflows, team presets and verified copy/recovery behavior.
- Adds the Array-reference interface, METADATA branding and Windows product identity.
- Adds inspection locks, SHA-256/BLAKE3 fingerprints, signature/extension review, exact duplicates, metadata comparison, batch editing with undo, controlled JSON/CSV reports and JSONL scanning.
- Includes a concrete Array adapter and distribution handoff.
- Repairs the incomplete ExifTool source archive in the earlier local bundle; this release includes the complete archive verified against its official checksum.
- Fixes Windows Unicode paths and metadata values by passing ExifTool arguments through UTF-8 input, with regression coverage for multiline values and option-like text.

## Qualification

The source includes the original 255 application checks and eight Array adapter contract checks. This GitHub release is published only after the Windows workflow rebuilds the native engine, tests the UI/native/desktop paths, builds both packages, and passes per-user installation, packaged-app launch and uninstall checks. The attached build provenance identifies this run and its commit.

This is an **unsigned preview release**. KI publisher signing and the canonical Array/Store free-utility listing remain separate publication work. Format-specific cleanup and verification scopes are documented in the source. Strict metadata removal does not redact document or pixel content.
