# METADATA 0.4.0 · Linux and Windows release candidate

A free standalone metadata utility by Kuykendall Industries, prepared for the Array launcher.

## Downloads

| Asset | Purpose |
|---|---|
| **Windows-x64-Setup.exe** | Per-user Windows installation, folder selection and shortcuts. |
| **Windows-x64-Portable.exe** | Run on Windows without installing. |
| **Linux-x64.deb** | Recommended for Ubuntu 24.04 x64; installs the app and required system dependencies. |
| **Linux-x64.AppImage** | Portable Linux candidate for compatible x64 desktops with glibc 2.39 or later. |
| **Source.zip** | Complete source, build scripts, tests, documentation, qualified Windows native engine and third-party licenses/sources. |
| **SHA256SUMS.txt** | SHA-256 integrity checks for every release asset. |
| **BUILD_PROVENANCE.json** | Common version, commit and platform build records; detailed evidence is in the two platform provenance files. |

All four desktop packages include Electron, the platform's native Rust engine, ExifTool, FFmpeg and ffprobe. Windows includes Perl. Linux uses the system Perl interpreter and Brotli module, which the Debian installer declares as dependencies. No account, activation, Node.js, Rust compiler or separate FFmpeg/ExifTool installation is needed.

### Ubuntu installation

```sh
sudo apt install ./KI-Metadata-Workbench-0.4.0-Linux-x64.deb
```

### AppImage

```sh
sudo apt install perl libio-compress-brotli-perl
chmod +x KI-Metadata-Workbench-0.4.0-Linux-x64.AppImage
./KI-Metadata-Workbench-0.4.0-Linux-x64.AppImage --appimage-extract-and-run
```

The Debian package is preferred for Ubuntu desktop integration and its sandbox profile. Electron-builder's AppImage desktop shortcut disables the Chromium sandbox; direct AppImage launches select sandbox behavior based on system support. The provenance records the behavior observed during testing. Linux qualification uses Ubuntu 24.04 x64. ARM64 and older glibc systems are outside this candidate's build targets.

## Included workspaces and capabilities

- Files, Overview, Inspect, Compare, Batch edit, Reports and Team presets.
- Strict JPEG/PNG/APNG/WebP metadata stripping with preserved encoded image content and verified output copies.
- Extended image/RAW, audio/video, PDF, Office and OpenDocument workflows.
- Locked inspection, SHA-256/BLAKE3 fingerprints, extension review, duplicate detection and JSONL scanning.
- Batch editing with undo, controlled JSON/CSV exports and team preset exchange.
- Array-reference interface, METADATA branding and the Windows Array integration handoff.
- Windows Unicode path and metadata handling, including multiline values and option-like text.

## Release qualification

Both Windows and Linux jobs must succeed before publication. They rebuild the native engines, test the UI and native operations, exercise actual desktop workflows, verify packaged application/resources, and perform installation acceptance. Linux additionally builds its media tools from included source and verifies real audio/video operations with those bundled tools. Release assembly requires both platform packages to match the same source commit, version, sizes and checksums.

This is an **unsigned release candidate**, published as a GitHub prerelease. Signing and the authenticated Array/Store distribution envelope remain separate. Cleanup scope depends on the file format; strict metadata stripping does not remove visible content or document body content.
