# METADATA 0.4.1 — Software and privacy notice

This release adds a Software and Privacy Notice to the desktop navigation, Help menu and command menu. It is available before opening a file and remains available offline. The notice explains local file processing, saved settings and history, original-file backups, deliberate exports, third-party licenses and privacy requests. Contact and privacy buttons open the corresponding KI page in your browser without attaching files.

The app remains a free standalone utility with no account, activation, telemetry or automatic updater. Its existing metadata editing, verification and backup behavior is unchanged. Uninstalling keeps local settings and history; the notice explains how to find and remove local records.

The release workflow checks the notice and contact controls in real Electron and in the installed Windows and Linux packages, alongside the existing native file-processing and installation checks. Both platform jobs must pass before these downloads are published. The checksums and build provenance identify the exact source and packages.

These are unsigned release candidates. Existing v0.4.0 downloads and their records are preserved. This release does not activate Array distribution or change another product's license.

Read the [Software and Privacy Notice](https://github.com/seismicgear/ki-metadata-workbench/blob/v0.4.1/LEGAL.md).
